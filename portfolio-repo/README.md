# Sumit Naykodi — Detective Portfolio

Single-file site (HTML, CSS, vanilla JS, WebGL2). Open `index.html` in a browser or serve it from any static host.

- Intro sequence: loader, disclaimer, sound choice
- Evidence wall: WebGL2 torch lighting, soft shadows, glossy highlights, threads and pins
- Inner pages: About, Resume, My Works, Live Websites, Music Playground, Reviews, Design gallery
- Sound effects are synthesised with the Web Audio API (no music yet)

Note: all images are embedded in `index.html` as base64 (about 5 MB).
